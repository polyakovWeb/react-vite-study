## 📋 О проекте

Данный проект создан с целью глубокого практического освоения современного стека frontend-разработки с упором на **Feature-Sliced Design (FSD)** и **комплексное тестирование**.

Это не просто учебный пет-проект, а полноценный шаблон, демонстрирующий подходы к построению масштабируемых, поддерживаемых и надежных приложений на экосистеме React.

---

## 🧩 Стек технологий

| Категория | Технологии |
|-----------|------------|
| **Архитектура** | [Feature-Sliced Design](https://feature-sliced.design/) (FSD) |
| **Фреймворк** | React 19 (хуки, Actions, `use` API) |
| **Стейт-менеджмент** | Redux Toolkit + RTK Query |
| **Язык** | TypeScript 5.x |
| **Сборка** | Vite |
| **Тестирование (Unit)** | Vitest + React Testing Library |
| **Тестирование (E2E)** | Cypress |
| **Интернационализация** | i18next |
| **Линтинг/Форматирование** | ESLint, Prettier |
| **Git хуки** | Husky + lint-staged |
| **CI/CD** | GitHub Actions |
